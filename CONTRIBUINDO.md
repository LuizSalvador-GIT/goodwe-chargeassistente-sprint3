# Histórico de contribuições antes da entrega

Cada integrante deve revisar uma parte real do projeto, fazer uma alteração própria e criar o commit usando sua conta Git. Não altere autor ou e-mail para simular participação.

Sugestão de divisão: revisão funcional/demonstração; eval/evidências; prompts/guardrails; relatório/apresentação; integração LangChain. O grupo deve ajustar a divisão ao trabalho que efetivamente realizar.
